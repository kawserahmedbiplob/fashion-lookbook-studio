Firebase setup steps
  1. Go to console.firebase.google.com and create a project (free Spark plan).
  2. Open Build → Authentication → Get started → Sign-in method, enable Email/Password.
  3. Open Build → Realtime Database → Create Database. Copy its Database URL.
  4. In Project settings, add a Web app and copy its API key, Project ID and Auth domain.
  5. In Realtime Database → Rules, use the secure rules shown below and click Publish.
  6. Fill the fields above, click Save settings, then Create account. Use the same email/password on your phone and PC.
{\n  "rules": {\n    "users": {\n      "$uid": {\n        ".read": "auth != null && auth.uid === $uid",\n        ".write": "auth != null && auth.uid === $uid"\n      }\n    }\n  }\n}

Keep the database rules private to each signed-in account. Do not publish rules that allow anyone to read or write all data.
